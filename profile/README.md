<h2 align="center">MacHub</h2>

<p align="center">
  <b>Play your Windows games on a Mac with Apple silicon.</b><br>
  A native macOS app with its own Windows engine (Wine, DXMT, DXVK), Steam for Windows built in, and safe mods.<br>
  Free and open source.
</p>
